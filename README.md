# ☀️ 지면 환경 기반 온열질환 위험도 분석 대시보드
> **Streamlit 기반 데이터 시각화 및 인사이트 도출 프로젝트**

---

## 📌 1. 프로젝트 개요 (Overview)
본 프로젝트는 기존 기상청의 음지 1.5m 대기온도 중심 경보 체계가 가진 한계를 파악하고, **아스팔트·콘크리트 등 불투수 지면에서 발생하는 복사열(노면온도)과 온열질환자 발생 간의 실질적 상관관계**를 분석하기 위해 구축된 Streamlit 웹 대시보드입니다.

데이터 기반의 가설 검증(EDA, 공간 상관분석)을 통해 거시적 토목 지표의 한계를 규명하고, 실질적 취약 계층을 타겟팅한 핀포인트 개선안을 제시합니다.

---

## 🚀 2. 주요 분석 기능 (Key Features)

### 1️⃣ 지면 재질별 온열질환 발생 모형 분석
* 전국 온열질환 발생 장소를 **불투수지면 / 자연지면 / 실내공간**으로 재범주화
* 지면 재질 특성에 따른 전체 환자 발생 규모 및 비율 탐색 (Pie / Bar Chart)

### 2️⃣ 지역별 불투수율과 발생률 간 공간 상관성 검증
* 전국 시·도 및 시·군·구 단위의 **불투수 지면 비율**과 **인구 10만 명당 환자 발생률** 데이터 결합
* 이중축(Dual-axis) 차트를 활용한 매크로 가설 검증 (도시 전체 불투수율과 발생률 간 무상관 관계 입증)

### 3️⃣ 고위험 인공지면 노출 타겟 세그먼트 도출
* 인공지면(실외작업장 등) 사고 환자의 연령별·성별 데이터 교차 분석
* 복사열에 물리적으로 밀접하게 노출되는 **10세 이하 유아·청소년** 및 **실외 작업 노동자** 등 마이크로 취약 계층 규명

### 💡 4️⃣ 데이터 기반 정책 및 개선사항 제시
* 분석 결과를 바탕으로 한 3대 핀포인트 액션 플랜 (공간 타겟팅, 노면온도 지표 도입, 취약 계층 맞춤형 보호)

---

## 💡 3. 핵심 분석 결과 (Key Insights)
* **노면열의 직접성:** 대기온도보다 아스팔트·콘크리트의 지표면 노면열($50^\circ\text{C}+$)이 실외 활동자의 체감 열 스트레스와 실제 사고를 유발하는 직접적 요인입니다.
* **거시 지표의 한계:** 도시 전체의 불투수면 비율(토목 환경)보다 개인이 인공지면에 직접 노출되는 시간 및 직업군 특성이 위험도를 결정합니다.
* **취약 계층 규명:** 신장이 낮아 지표면 복사열에 가까운 **10세 이하 계층** 및 **실외 작업자**가 인공지면 열환경에 가장 무방비로 노출되어 있습니다.
